# План: Browser extension manager UI (React + Vite)

Челендж Frontend Mentor «Browser extension manager UI», рівень Junior.

## Прийняті рішення

- **Стек:** React 18 + Vite 5, чистий CSS (окремий файл стилів для кожного компонента, CSS-змінні для тем).
- **Дані:** `data.json` імпортується напряму в JS (`src/data/data.json`); картинки та шрифти лежать у `public/assets/`.
- **Фільтр:** на вкладках «Active» / «Inactive» картка зникає одразу після перемикання тумблера.
- **Порожній стан:** повідомлення, коли у списку немає карток (усі видалені або фільтр нічого не знайшов).
- **localStorage:** зберігаються тема, стани тумблерів і видалені розширення.
- **Тема за замовчуванням:** береться із системних налаштувань (`prefers-color-scheme`) і стежить за їхніми змінами наживо, поки людина не обрала тему кнопкою.
- **Логотип:** inline SVG, текст фарбується через `currentColor`.
- **Брейкпоінти:** 1 колонка → 2 колонки від 640px (`40em`) → 3 колонки від 1024px (`64em`).

## Компоненти

```
App                  ← тут живе весь стан
├── Header           (Logo + кнопка теми)
├── FilterBar        (заголовок + All / Active / Inactive)
├── ExtensionList    (сітка карток або EmptyState)
│   ├── ExtensionCard
│   │   └── Switch   (доступний тумблер)
│   └── EmptyState   (+ ResetButton, коли видалено все)
└── ResetButton      (під сіткою, коли є зміни)
```

## Стан (`App`)

| Стан | Значення | Що його змінює |
|---|---|---|
| `extensions` | масив розширень | тумблер, кнопки Remove і Reset |
| `filter` | `'all'` / `'active'` / `'inactive'` | кнопки фільтрів |
| `theme` | `'light'` / `'dark'` | кнопка теми |

Відфільтрований список **не зберігається окремо**, а обчислюється з `extensions` + `filter` під час кожного рендеру.

## Кроки

- [x] ✅ **1. Налаштування проєкту:** Vite + React, структура папок, шрифти Noto Sans, CSS-токени (палітра + семантичні змінні), reset.
- [x] ✅ **2. Статична розмітка (mobile):** `Header` з inline-логотипом, `FilterBar`, одна `ExtensionCard`; семантичний HTML, `aria-pressed` на фільтрах.
- [x] ✅ **3. Список і адаптивна сітка:** `.map()` по `data.json` з `key`, `<ul>/<li>`, сітка 1 / 2 / 3 колонки, однакова висота карток, заголовок і фільтри в одному рядку від 640px; компактні фільтри на екранах менше 360px (усі три в один рядок).
- [x] ✅ **4. Тумблер і перший стан:** компонент `Switch` (прихований `<input type="checkbox" role="switch">` + стилізована доріжка), `useState` для `extensions`, незмінне (immutable) оновлення `isActive` через `.map()`, `prefers-reduced-motion`.
- [x] ✅ **5. Фільтри й порожній стан:** стан `filter`, похідний список `visibleExtensions` (обчислюється, не зберігається), компоненти `ExtensionList` і `EmptyState` (`role="status"`, окреме повідомлення для кожного фільтра).
- [x] ✅ **6. Кнопка Remove:** видалення через `.filter()`, `aria-label="Remove <назва>"`, після видалення фокус переходить на заголовок списку (`useRef` + `tabIndex={-1}`).
- [x] ✅ **7. Hover- і focus-стани:** глобальна рамка `:where(...):focus-visible`, hover лише в `@media (hover: hover)`, нові токени станів (`--color-focus`, `--color-accent-hover`…), глобальний `prefers-reduced-motion`.
- [x] ✅ **8. Темна тема:** стан `theme` (ліниве початкове значення), `useEffect` ставить `data-theme` на `<html>`, скрипт у `index.html` проти «спалаху» світлої теми (`prefers-color-scheme`), блок `:root[data-theme='dark']` з токенами, `color-scheme`, іконки сонця й місяця, `aria-label` змінюється разом із темою.
- [x] ✅ **9. localStorage:** власний хук `useLocalStorage` для розширень (тумблери + видалення), з `try/catch` на випадок зіпсованого JSON або недоступного сховища; тема зберігається лише після кліку (до того діє системна), скрипт у `index.html` читає збережену тему до рендеру; фільтр навмисно не зберігається. Живе стеження за системною темою (`matchMedia` + `addEventListener('change')` з очищенням у `useEffect`) — лише поки людина не обрала тему кнопкою.
- [x] ✅ **9a. Кнопка Reset:** компонент `ResetButton`, повертає всі 12 розширень і стани тумблерів з `data.json`, а фільтр — на «All» (тему не чіпає). Під сіткою по центру видно лише тоді, коли список відрізняється від початкового (похідне `isModified`). Коли видалено все, Reset з'являється всередині `EmptyState` (prop `action`). Після натискання фокус переходить на заголовок. Стилі Remove і Reset об'єднані в спільний клас `.btn-outline`.
